# AutoParts Online Store

Responsive five-page auto parts website built with HTML, CSS, and Bootstrap. [View the site](https://mikosh001.github.io/autoparts-online-store/).

## Pages

- `index.html` — Home
- `categories.html` — Categories
- `products.html` — Products, filters, cart, and comparison table
- `about.html` — About
- `contact.html` — Contact form

Open `index.html` in a browser to run the site. Forms use the visitor's email app; no JavaScript is required.
